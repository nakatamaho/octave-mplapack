# mplapack-interop 0.3.1 numerical API

The 0.3.1 release provides dense, arbitrary-precision real and complex `mp`
values for the following public operations:

| Operation | Supported forms | Native backend |
|---|---|---|
| construction/precision | `mp`, `mpbits`, `mpdigits` | MPFR/MPC storage |
| arithmetic | `+`, `-`, `.*`, `./`, unary signs, `*`, `\`, `/` | native MPFR/MPC; `Rgemm`/`Cgemm`; `Rgesv`/`Cgesv`/`Rgelss`/`Cgelsy` |
| structure | indexing, assignment, transpose, ctranspose, reshape, concat | native operation-owned storage |
| factorizations | `chol`, `qr`, pivoted `qr`, `lu` | `Rpotrf`/`Cpotrf`, `Rgeqrf`/`Cgeqrf`, `Rgeqp3`/`Cgeqp3`, `Rgetrf`/`Cgetrf` |
| norms | vector and dense matrix supported norm forms | native MPFR/MPC; `Rlange`/`Clange`; `Rgesvd`/`Cgesvd` |
| determinant/inverse | `det`, `inv` | `Rgetrf`/`Rgetri`; `Cgetrf`/`Cgetri` |
| SVD | values, full/economy factors | `Rgesvd`/`Cgesvd` |
| rank/condition | `rank`, `cond`, `rcond` | singular values; `Rgecon`/`Cgecon` |
| standard eig | structured/general, balance/nobalance, vector/matrix, left vectors | `Rsyevd`/`Cheevd`; `Rgeevx`/`Cgeevx` |
| generalized eig | `eig(A,B)`, `chol`/`qz`, vector/matrix, left vectors | `Rsygvd`/`Chegvd`; `Rggev`/`Cggev` |
| right division | dense `A / B`, scalar and matrix forms, rank-deficient minimum norm | conjugate-transpose solve; `Rgesv`/`Rgelss` or `Cgesv`/`Cgelsy` |

Every numerical operation selects one operation precision from its stored
operands. It normalizes native temporaries to that precision, enters the
corresponding MPFR or MPFR/MPC scope, and returns operation-owned uniform
storage. Destructive LAPACK calls never receive public storage directly.
Existing values retain their precision when `mpbits` changes. No supported
complex operation silently falls back to builtin binary64 arithmetic, and
real-only operations remain on real MPLAPACK paths.

Generalized eigensystems use `A*V = B*V*D`; three-output forms additionally
return `W` satisfying `W'*A = D*W'*B`. Real QZ conjugate pairs are represented
as complex `mp`, and `beta = 0` preserves an infinite eigenvalue. An exact
symmetric/Hermitian pair uses the definite driver by default when `B` is
positive definite; `"qz"` forces QZ and `"chol"` requires the structured pair.

The tested interface is GNU Octave 11.1.0 with the controlled MPLAPACK MPFR
backend. Unsupported or intentionally deferred APIs include sparse and
N-dimensional matrix values, standalone `qz`, `schur`, `hess`, `expm`, `logm`,
general unimplemented matrix functions, powers, and comparisons/logical
values. These fail through package-owned or clean Octave diagnostics without
implicit binary64 conversion. Dense right division is implemented through
the conjugate-transpose identity `(B' \ A')'`; scalar denominators use native
element-wise division.
