## Release scope

The frozen public API is the dense real `mp` v0.1.0 surface in
[`v0.1-api.md`](v0.1-api.md): precision-controlled construction, native
arithmetic and structure, dense multiplication and solve, Cholesky, full and
pivoted QR, and LU. Complex, sparse, N-D, unsupported reductions/functions,
and update APIs remain outside this release. The final Git tag and PPA are not
created by M23.

## PPA handoff

PPA1 must package an MPLAPACK source revision equivalent to the validated
interface before PPA2 packages `octave-mplapack`. PPA2/PPA3 must use exactly
the RC commit, archive filename, and checksum recorded above. PPA4 is the
later public PPA/final-release gate; complex support does not block this
real-only handoff.
