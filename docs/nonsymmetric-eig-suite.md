# Difficult nonsymmetric eigensystem suite

The repository includes a reproducible experiment suite for dense general
eigenproblems. It is an example and QA harness built on the existing public
`mp`, `mpbits`, `eig`, `norm`, `real`, `imag`, `conj`, and `char` interfaces;
it does not add a package-level numerical API.

Run the compact smoke wall from a checkout with the installed MPLAPACK stack:

```sh
PKG_CONFIG_PATH=/home/docker/opt/octave-mplapack-stack/lib/pkgconfig \
LD_LIBRARY_PATH=/home/docker/opt/octave-mplapack-stack/lib \
CPATH=/home/docker/opt/octave-mplapack-stack/include \
tools/run-nonsymmetric-eig-suite.sh smoke
```

Use `demo` for the 40-row wall, or pass a second argument to write a new
result bundle:

```sh
tools/run-nonsymmetric-eig-suite.sh demo /path/to/new-results
```

An output directory must be empty. The writer refuses to overwrite an existing
result file. It creates `summary.tsv`, `eigenvalues.tsv`, `environment.txt`,
and `report.md`; `options.plot = true` additionally creates `spectrum.png`.
The TSV eigenvalues and metrics retain MP text via `char(mp)`. The optional
plot is only a display conversion and is not numerical evidence.

## Five difficult input representations

The default suite runs five representations, with `eig (A, "balance")` and
`eig (A, "nobalance")`:

1. A Hadamard orthogonal similarity of an upper-bidiagonal matrix. Its exact
   eigenvalues are `1:n`, while large superdiagonal coupling exposes the
   difference between a small residual and a well-conditioned eigenvalue.
2. The Frank matrix, whose positive eigenvalues include reciprocal pairs and
   whose independent reference is obtained from a symmetric tridiagonal
   problem.
3. The companion matrix of the exact Wilkinson polynomial
   `prod(x-(1:n))`. Coefficients are generated by an MP recurrence rather than
   by a rounded builtin polynomial helper.
4. The original Forsythe form `I + N + 2^(-a*n) e_n e_1^T`.
5. The explicitly scaled Forsythe form `I + 2^(-a) P`, with `P` the cyclic
   shift. The two Forsythe forms are diagonally similar, but the small
   coupling is represented differently in native binary64.

The default smoke cases produce 30 rows:

```text
5 representations × 2 eig modes × (native + 128-bit + 256-bit MP)
```

The default demo cases produce 40 rows:

```text
5 representations × 2 eig modes × (native + 128-bit + 256-bit + 512-bit MP)
```

The native rows are an explicit binary64 input control. They are not used to
construct or validate the MP model. For every MP row, the actual solver
output is promoted to an evaluation precision and the following are measured
there:

```text
A*V - V*D
W'*A - D*W'
column right/left residuals
eigenvalue absolute and relative bottleneck matches
left/right eigenvector condition estimates
```

The left-vector convention is `W'*A = D*W'`, so the corresponding column
residual uses `A'*w - conj(lambda)*w`. Eigenvalue order is not assumed: the
suite uses a deterministic minimum-bottleneck one-to-one matching. A reference
match is marked unresolved when its independent low/high precision agreement
does not meet its declared limit.

## Precision and input construction

Each MP constructor temporarily establishes its requested `mpbits()` value,
constructs the complete matrix, and restores the caller's ambient default.
Existing MP objects are not reconstructed when the default changes. The
solver receives an MP matrix at the selected work precision; no MP path calls
builtin binary64 `eig`, and no native row is substituted for an MP row.

The suite's self-test includes 1024-bit `2^-700` and 2048-bit `2^-1500`
tail canaries. The Forsythe stress constructor also checks that a 2048-bit
`2^-1600` MP coupling remains nonzero while the deliberately rounded native
control underflows. This is input provenance evidence, not a claim that the
native control is accurate.

Use `mp_eig_suite_selftest` for constructor, reference, matching, precision,
and lifetime-oriented focused checks. The full focused test is
`test/test_nonsymmetric_eig_suite.m`. The top-level runnable example is
`examples/13_nonsymmetric_eig_suite.m`.

## Interpretation

A small backward or eigenvector residual does not by itself prove a small
forward eigenvalue error for a nonnormal matrix. Report the condition estimate,
the matched forward error, and the actual-input residual together. Balancing
is a solver option to compare, not an assumption about the mathematical
model. The reference paths are structured MP checks; they are independent of
the general solver call but still use the package's MP arithmetic/backend and
must not be described as an external-library oracle.

The stress profile is available for extended local runs. The mandatory
acceptance wall is the deterministic smoke/demo pair above; stress cases are
not silently substituted for those rows.
