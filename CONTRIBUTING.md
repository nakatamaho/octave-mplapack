# Contributing

Read `AGENTS.md` and the active milestone before making changes. Work against
an explicit milestone and keep each contribution within that milestone's
scope and gate.

Include automated tests with every user-visible numerical change. Keep source,
comments, tests, documentation, commit messages, and metadata in English. Do
not vendor MPLAPACK or copy its implementation into this repository. Do not
add another numerical backend before the MPFR baseline is complete. Avoid
unrelated formatting churn, and update contracts when public behavior changes.
