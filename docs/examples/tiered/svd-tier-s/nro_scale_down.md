# NRO scale-down control (Tier S1)

## Quick idea

S1-NRO-SCALE-DOWN is the underflow-boundary companion to the NRO two-level
matrix. It keeps the exact block construction and makes the entire matrix
smaller by a dyadic factor $2^{-600}$. The question is whether a genuine MP
path preserves scale and factor identities without silently converting the
result to binary64.

## Mathematical problem

The demo uses $m=16$, $b=40$, and scale exponent $s=-600$. Let $H_m$ be a
Sylvester Hadamard matrix and $B=H_m\mathrm{diag}(2^b)$. The unscaled
block is

```math
A_0=\begin{bmatrix}I_m&B\\0&I_m\end{bmatrix},\qquad
A=2^s A_0.
```

The singular values of $A$ are $2^s$ times the reciprocal pairs generated by
$\beta=\sqrt{m}\,2^b$:

```math
a=\frac{\sqrt{\beta^2+4}+\beta}{2},\qquad
b_{\mathrm{small}}=\frac{2}{\sqrt{\beta^2+4}+\beta}.
```

## Why this problem is numerically difficult

A large scale stresses exponent range and norm calculations while preserving an exact dyadic model. It is not the same as merely printing a large number after a binary64 computation. The matrix must be built, factorized, and reconstructed at a precision that retains the scale; overflow or a hidden conversion changes the measured problem. The reciprocal pair is still ill-conditioned, so range safety and forward accuracy are separate questions.

## What the Octave example computes

The matching [nro_scale_down.m](../../../../examples/tiered/svd-tier-s/nro_scale_down.m) selects the demo scale-down case and runs public svd on the scaled dense matrix. It records the scale exponent, checks the block inverse relation after scaling, compares all singular values with the scaled analytic reference, and checks reconstruction and unitarity. It does not rescale the measured result into binary64 before computing diagnostics.

## Construction and exactness

The Hadamard entries, $2^b$ block, and $2^{-600}$ scale are exact dyadics in the intended MP range. The constructor verifies the source hash and the scaling identity $A=2^{-600}A_0$. The stable reciprocal expression is used for the small values. An exactness proof checks the block inverse and dyadic range guard independently of SVD.

## Diagnostics

For the measured $A=U\Sigma V^{\mathsf H}$, use

```math
A=U\Sigma V^{\mathsf H},\qquad
r_{\mathrm{svd}}=\frac{\lVert A-U\Sigma V^{\mathsf H}\rVert_F}{\lVert A\rVert_F},
\qquad r_U=\lVert U^{\mathsf H}U-I\rVert_F,\quad r_V=\lVert V^{\mathsf H}V-I\rVert_F.
```

Report absolute scale, relative singular-value error, and whether any norm operation overflowed or underflowed.

## Backward error versus forward error

$r_{\mathrm{svd}}$ measures a factorization equation defect relative to the stored scaled matrix. Forward error in the smallest singular value is affected by the reciprocal condition number and by scaling. A small relative reconstruction residual is not a proof that the small pair has its displayed digits.

## What arbitrary precision changes

The input/source precision is the exact dyadic scale-down model. Arithmetic/work precision provides the exponent range and significand needed for the scaled products and SVD. Mathematical conditioning remains that of the unscaled NRO pair; multiplication by $2^{-600}$ changes units, not the relative condition. More bits protect the range and tail but do not make the reciprocal pair well-conditioned.

## Parameter boundary and comparison protocol

The scale exponent is part of the model identity. Keep the unscaled A0, the scaled A, the scale exponent, and the scaled reference values in separate records. Compare relative quantities only after the scale has been accounted for; a binary64 presentation can make a perfectly valid MP value look ordinary while hiding whether the computation ever represented its exponent. The runner must therefore perform norms, reconstruction, and value matching before any optional display conversion.

This is a range control, not a request to weaken the acceptance threshold. If an intermediate overflows, underflows, or loses a dyadic scale, record the exact operation and the changed value. A run that succeeds after silently rescaling the input is a different experiment. Conversely, a stable scaled result does not prove that the reciprocal NRO pair is well conditioned. The useful conclusion is narrower: the public MP path preserved the declared scale and satisfied its factorization checks.
## Reading the output

Confirm the scale exponent and source hash first. Then inspect whether the largest value, smallest value, and reciprocal relation survived. A PASS requires reconstruction, unitarity, spectrum matching, and range checks. A binary64 display of a final result is presentation only and must not be used to claim the computation was binary64.

## Common mistakes

Do not multiply by $2^{600}$ before measuring and call the result the original run, use $A^{\mathsf H}A$ as the primary path, use cancellation for the small value, or infer range safety from a finite display. Do not treat a range failure as evidence that the mathematical model is wrong.

## Scope of the claim

This page explains one fixed SVD model and the precise object that the runner measures. Changing a dimension, dyadic exponent, scale, phase, gap, or zero entry changes the source matrix and requires a new case identity. That is especially important for repeated and rank-deficient examples: a zero gap is not a tiny gap, and an exact zero is not merely a small positive singular value.

The analytic spectrum or projector is an independent model check. It is not inserted into the measured factorization, and the public dense SVD is not silently replaced by a structured bidiagonal or totally-nonnegative algorithm. Reconstruction, unitarity, value-wise forward error, and subspace comparisons answer different questions. The runner records all of them with the input and arithmetic precision roles. Binary64 is permitted only at an explicitly declared presentation boundary; it is never an unreported numerical fallback.
## Range-specific interpretation

The scale-down row is useful only when the reported norms are computed in the same MP range as the matrix. The smallest entries and singular values must remain distinguishable from an underflowed zero. Record exponent-range checks for inputs, intermediate products, norms, and reconstruction separately. A finite output after an implicit up-scale is not evidence for this case. The scale factor changes units, while the relative condition of the NRO block is unchanged.
